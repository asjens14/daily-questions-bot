Daily Question bot for a discord server  
Commands:  
/dq simple [question]: Submit a daily question >> submit a simple question  
/dq poll [question][option 1][option 2](option 3)(option 4)(option 5)(option 6)(option 7)(option 8([option 9)(option 10)(multi-select) >> submit a poll  
/help >> show available commands  
  
Mod Commands:  
/dqsend >> send question to channel  
/queue >> show question queue  
/updatenum >> update question number
